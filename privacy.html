隱私權政策

適用工具：Krisnote Backup
更新日期：2026 年 10 月 7 日

Krisnote Backup 是由使用者在自己的 Windows 電腦執行的個人 Obsidian 備份工具。本政策說明工具處理 Google 使用者資料與本機筆記的方式。

存取的資料與目的

  • Google 帳號 Email：確認授權帳號符合備份設定。
  • Google Drive 資料夾與備份檔案資訊：確認目的地與寫入權限，驗證檔案名稱、位置、大小與 checksum，並管理本工具紀錄中的備份。
  • 使用者指定的本機筆記資料夾：讀取筆記、附件、隱藏檔與設定，建立並驗證 ZIP 備份。
  • OAuth 授權資料：取得 access token，並使用 refresh token 在使用者授權有效期間執行背景備份。

工具要求 https://www.googleapis.com/auth/drive scope。此 scope 可授予廣泛的 Drive 檔案讀寫權限；工具使用該授權執行設定中的備份工作，不提供瀏覽整個 Drive 的功能。

資料傳送與分享

ZIP 備份透過 HTTPS 傳送至使用者指定的 Google Drive 資料夾。Google 帳號驗證、token 交換與檔案資訊查詢會與 Google 服務交換必要資料。

工具沒有由維護者營運的備份伺服器，不會將筆記或 Google 授權資料傳送給維護者，也不會將 Google 使用者資料出售、用於廣告或模型訓練。Drive 檔案的可見範圍由使用者的 Google Drive 分享設定決定。

本機儲存與保護

設定、備份紀錄、執行日誌與本機 ZIP 儲存在使用者電腦。OAuth client secret 與 refresh token 使用 Windows DPAPI 加密，綁定目前 Windows 使用者；工具不儲存 Google 密碼。access token 用於執行期間的 API 請求。

本機 ZIP 未加密；雲端 ZIP 使用 Google Drive 的存取控制。使用者應自行管理電腦、Drive 帳號及分享權限。執行日誌與備份紀錄可能包含檔案名稱、路徑、檔案 ID、執行時間與錯誤資訊。

保留與刪除

新備份成功上傳並驗證後，本機與雲端各保留最新 2 份成功備份。工具只處理自己紀錄並查核的舊備份：刪除本機 ZIP，並將對應的雲端 ZIP 移到 Google Drive 垃圾桶。工具不永久清空垃圾桶；永久刪除由使用者及 Google Drive 垃圾桶機制處理。

驗證或清理失敗時可能暫時保留超過 2 份備份；失敗或未登錄的檔案留待使用者檢查。來源筆記不會因備份保留規則而刪除。

解除安裝會停用排程，但保留本機資料。使用者可自行刪除本機 ZIP、設定、憑證及日誌，並在 Google Drive 刪除雲端備份。

撤銷授權

使用者可在 Google 帳戶的第三方連線撤銷 Krisnote Backup 授權。撤銷後，工具無法繼續存取 Drive，需重新授權才能恢復備份。

網站與第三方服務

此介紹網站沒有表單、登入、追蹤程式或備份上傳功能。若網站由 GitHub Pages 託管，GitHub 可能依其服務運作記錄必要的技術資料；請參閱 GitHub 隱私權聲明。Google 服務另受 Google 隱私權政策規範。
